**Securomatic** assesses the security advisories that scanners report
against a product's container images, decides which ones actually
affect it, and writes signed OpenVEX documents saying so, so its
customers never have to look at an irrelevant vulnerability again.

- [securomatic.dev](https://securomatic.dev): the public keys and the
  basis record's specification, for checking what Securomatic publishes
- [securomatic/public](https://github.com/securomatic/public): the same,
  as a repository
